# 2026-11-11 R10 reserved-address rulings (Asia/Taipei)

The following are A 組領航員裁示（未經使用者確認）. They fall within 總召 §21:09 R10 (recorded in `2026-11-09-case-flow-addendum.md`; that PM ruling is also not confirmed by the user).

1. Reject both `src_ip` and `dst_ip`. Fixtures that used TEST-NET or other rejected ranges as still-accepted addresses were moved to other public addresses in a test-only commit first.
2. ingest rejects exactly: loopback `127/8` and `::1`; link-local `169.254/16` and `fe80::/10`; multicast `224/4` and `ff00::/8`; `255.255.255.255`; `0.0.0.0/8` and `::`; `240/4`; TEST-NET `192.0.2/24`, `198.51.100/24` and `203.0.113/24`; `2001:db8::/32`; `3fff::/20`. Not in the ingest list: `100::/64`, `2001:2::/48`, `198.18/15`. `::ffff:`-mapped addresses are unwrapped to v4 before checking (`::ffff:127.0.0.1` is rejected).
3. Return 400 as `{ error: "位址為保留或文件範圍" }`, with no `issues` and no address.
4. Add a `reason` column to `flow_rejections` (migration follows the R-B pattern: short DDL plus `lock_timeout`). The reason has no IP. Write one row per request, not per field. Health shows the 24h count (`reserved_rejected_24h` on ingest `GET /v1/health`). Logs record counts only.
5. Order: after authentication (an unauthenticated request must never write `flow_rejections`), after contract format, before the app_id 403, alongside the ts bounds (ts checks run first in that segment; a request that is both too old and reserved still gets the ts error).
6. Tighten only `hostCidr` so it excludes Class E and the documentation ranges (same list as 2); the judge then skips instead of opening a case. Do not change `parseCidr`, case writes, or the contracts (except the new export).
7. The remaining B5 is item 6 only.
8. New export `isReservedForIngest(ip)` in `packages/contracts`, used by ingest and `hostCidr`. Keep control-api's `isGlobalUnicast` separate.

R1 (also this slice, not ingest): `isGlobalUnicast` treats `::/96`, `::ffff:0:0:0/96`, `100::/64`, `2001:2::/48` and `3fff::/20` as non-global.

## Security review follow-ups (A 組領航員裁示（未經使用者確認）)

- R10-b: The following are deliberately not blocked at ingest: IPv4-compatible `::7f00:1`, deprecated site-local `fec0::/10`, and loopback embedded in NAT64 `64:ff9b::` and 6to4 `2002::/16`. The judge's skip remains the second line of defence.
- R10-c: Reserved is checked before the app_id 403, so a request that is both reserved and unbound is recorded as `reserved` and the `unbound_app` count may be low.
